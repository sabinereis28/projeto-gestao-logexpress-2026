# 05 - Pesquisa Operacional e Otimização Algorítmica

Esta pasta contém as modelagens matemáticas, bases de parâmetros e algoritmos em Python (biblioteca PuLP) desenvolvidos para a LogExpress.

## 📁 Arquivos da Pasta:
- **`modelo-matematico.md`**: Equações em LaTeX de Maximização de Lucro e Minimização de Custos.
- **`otimizacao.ipynb`**: Notebook Python executável no Google Colab com a resolução dos dois problemas e testes *What-If*.
- **`dados-de-entrada.csv`**: Parâmetros de custos, horas e combustível.
- **`resultados.md`**: Relatório de resultados das simulações e Análise Crítica de negócios.

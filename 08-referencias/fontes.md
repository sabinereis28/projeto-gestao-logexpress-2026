# 08 - Referências Bibliográficas, Tutoriais e Ferramentas

## 1. Ferramentas e Plataformas de Desenvolvimento
- **GitHub**: Plataforma de hospedagem de código e controle de versão. Utilizado para o versionamento do repositório (`projeto-gestao-logexpress-2026`) e organização dos documentos em Markdown (`.md`). Disponível em: <https://github.com/>.
- **Google Colaboratory (Colab)**: Ambiente de notebooks Python em nuvem. Utilizado para a execução dos scripts de ETL (`analise.ipynb`) e otimização algorítmica (`otimizacao.ipynb`). Disponível em: <https://colab.research.google.com/>.
- **Microsoft Excel / Google Sheets**: Software de planilhas eletrônicas utilizado para a montagem de tabelas de custos, cronograma e matrizes do projeto.
